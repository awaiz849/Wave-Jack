# WaveJack — project context

Shazam-style audio fingerprinting app (college project, portfolio piece).

## Stack

- Backend: FastAPI + Uvicorn, librosa/scipy/numpy fingerprinting (STFT peaks -> SHA-1 pair hashes -> time-offset voting), ffmpeg for conversion, Supabase (Postgres) for storage
- Frontend: React 19 + TanStack Start/Router + Vite + Tailwind v4 + shadcn/ui + Framer Motion. Originally generated by Lovable.dev (has quirks).
- Auth: Supabase Auth (email/password). Tables: songs, fingerprints, search_history, users.
- Realtime: WebSocket /ws/recognize streams MediaRecorder chunks; REST /identify handles file upload.

## Run

- Backend: cd backend && venv\Scripts\activate && uvicorn main:app --reload --port 8000
- Frontend: cd frontend && npm run dev (port 8080)
- Needs ffmpeg on PATH.
